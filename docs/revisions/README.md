# Versioned addenda for existing Markdown files

These appendices are designed to be merged into existing documents while retaining original requirement IDs, detailed schema columns, and historical sections. An interim script can append each as an expressly authoritative v2 appendix. The final editorial pass should integrate changes into original sections and remove superseded contradictions; **never** silently replace `TASKS.yaml` or 156 task cards.

Canonical technical detail lives in `docs/architecture/`. These addenda are the human-readable delta for old source documents, not independent new applications.
