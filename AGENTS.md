# app-starter-kit — AI Coding Agent

Repository saat ini **baru berisi Next.js bawaan di root**, belum monorepo. Baca [README](README.md), [ARCHITECTURE](docs/ARCHITECTURE.md), [ROADMAP](docs/ROADMAP.md), dan [AGENT-WORKFLOW](docs/AGENT-WORKFLOW.md) sebelum melakukan perubahan.

## Kontrak ringkas

1. Gunakan branch `dev` atau feature branch turunannya; **jangan** mengubah `main` tanpa instruksi khusus.
2. Jangan jalankan ulang `create-next-app`. Pada fase P01 **migrasikan** app existing ke `apps/web`; jangan menimpa source awal.
3. Gunakan npm/npx, TypeScript strict, satu root lockfile pada monorepo. Hono API, worker, MySQL/Drizzle dan RBAC harus diimplementasikan secara bertahap.
4. Kerjakan **satu atomic task** dengan siklus RECOVER → IMPLEMENT → TEST → VERIFY → CHECKPOINT → NEXT. Tidak ada script Python task registry lama; tracking awal cukup roadmap, commit, dan checkpoint ringkas.
5. Uji yang relevan setelah edit terakhir; jangan menandai hasil tanpa evidence. Auth/RBAC, migration, backup/restore dan deployment memerlukan review independen sebelum gate.
6. Pisahkan UI Next, domain/API Hono, worker BullMQ dan shared package. Cek permission di server untuk semua operasi private.
7. Jangan akses, hardcode atau log secret; jangan lakukan destructive test pada database nyata, production deploy, restore, atau rotasi credentials tanpa persetujuan eksplisit.
8. Untuk Node.js/Next versi terpasang, verifikasi API dokumentasi dari dependency lokal sebelum mengubah kode. Pertahankan rule block autogenerated Next.js di bawah.
